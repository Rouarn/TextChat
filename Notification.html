Notification API 简介

Notification API 允许网页或应用程序向用户发送通知，这些通知显示在浏览器窗口外部，即使用户当前不在相关网站上也可以看到。

基本用法

使用Notification API需要以下步骤：

  1. 检查浏览器支持情况
  2. 请求通知权限
  3. 创建和显示通知

权限状态

代码示例

请求通知权限：

// 请求通知权限 Notification.requestPermission().then(function(permission) { if (permission === 'granted') { console.log('通知权限已授予'); } });

创建简单通知：

// 创建简单通知 if (Notification.permission === 'granted') { new Notification('标题', { body: '通知内容', icon: '/path/to/icon.png' }); }

通知选项

  • body: 通知的主要内容
  • icon: 显示在通知中的图标URL
  • image: 显示在通知中的图像URL
  • tag: 通知标签，用于替换相同标签的旧通知
  • requireInteraction: 通知是否需要用户交互才会关闭
  • actions: 通知操作按钮数组
  • silent: 通知是否静音（不播放声音或振动）
